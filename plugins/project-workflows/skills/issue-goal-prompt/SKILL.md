# 任务目标提示词

读取用户给出的任务、来源文档和工作仓库规则，提取目标、范围、关键约束与完成条件。来源可以是当前用户描述，不强制要求 Issue 标识。

只读与任务相关的计划或恢复摘要；已有事实优先引用，避免把整套规则和运行记录复制到新提示词。

提示词应包含：
- 目标与验收行为；
- 真实仓库、文件或接口入口；
- 用户明确的包含/排除范围和已授权动作；
- 必要实现步骤、验证入口及恢复条件。

参考 references/goal-prompt-template.md，按任务需要删去不适用字段，不发明执行模式或固定状态机。

用户要求交接文件，或需要跨会话恢复时，可保存到工作项目 .agents/state/；保留仍然有效的恢复信息。否则直接返回提示词，不因固定字符数自动创建文件。无 Issue 时使用清楚的任务主题命名。

生成提示词的授权不自动包含其描述的实施和外部动作；用户已明确要求继续执行时，遵循该授权，不因本技能再次暂停。
