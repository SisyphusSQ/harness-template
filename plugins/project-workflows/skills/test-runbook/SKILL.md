# 验证 Runbook

读取工作项目 AGENTS.md、相关代码/接口契约及现有 runbook，确认用户要求编写、执行还是回写。优先复用现有脚本和证据入口。

执行前说明真实目标环境、副作用、临时数据与清理方式。结合当前请求和已有授权继续工作，只有超出范围或影响无法确认时询问。

Runbook 包含目标与成功标准、环境与前置条件、步骤及预期结果、失败恢复、清理和结果摘要。若项目有 docs/test/RUNBOOK_TEMPLATE.md 可参考；缺少模板时直接组织内容。

- 只运行与改动及验收相关的检查，已有有效结果优先复用；提交/发版收尾遵守不重复测试的约定。
- 结果集中写入 runbook 一处，计划、state、runs 只引用，避免多份状态漂移。
- 未执行、失败、阻塞和清理残留按实际记录，不写成通过。
- 提交文档只保留脱敏摘要；不写 token、Cookie、连接串、数据库主机、敏感主键或私有临时地址。
- 原始输出保存在 .agents/runs/ 或其它受控本地位置，不自动提交或写入外部系统。
